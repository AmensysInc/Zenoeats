================================================================================
 ZENOEATS - URL REFERENCE
================================================================================

 Local development. Replace "spicehouse" with any restaurant slug.
 Production swaps "zenoeats.local:8443" for "zenoeats.com".

 IMPORTANT: Development is HTTPS only. Browse through nginx at
 https://<slug>.zenoeats.local:8443 -- there is no plain-HTTP address. The
 restaurant is resolved from the Host header, so a bare localhost address
 will NOT work.

 Hosts file entries needed (one per restaurant slug you open):
   127.0.0.1  zenoeats.local
   127.0.0.1  spicehouse.zenoeats.local
   127.0.0.1  admin.zenoeats.local


--------------------------------------------------------------------------------
 0. HTTPS SETUP
--------------------------------------------------------------------------------
 nginx will not start without the certificate (README "Running it", step 3).
 Once, from the repository root:
   bash scripts/local_https_cert.sh
 For the padlock, trust the local authority once (PowerShell):
   Import-Certificate -FilePath "$env:USERPROFILE\zenoeats-secrets\local-ca\ca.crt" -CertStoreLocation Cert:\CurrentUser\Root
 Then start as usual (make infra, or make up-all).

 In production (real domain, no port; publicly trusted certificate):
 Storefront             https://<slug>.<domain>/
 Staff portal           https://<slug>.<domain>/manage
 Admin portal           https://admin.<domain>/admin
 Legal pages            https://<domain>/legal/privacy  (/terms, /refunds, /data-deletion)
 Health (monitors)      https://<domain>/health/ready   and  /health/operations

 4. LOCAL SERVICES & PORTS
--------------------------------------------------------------------------------
 nginx (the only entry) https://<slug>.zenoeats.local:8443
 Health (liveness)      https://spicehouse.zenoeats.local:8443/health
 Health (readiness)     https://spicehouse.zenoeats.local:8443/health/ready
 Menu images            https://spicehouse.zenoeats.local:8443/images/restaurants/{restaurant_id}/{items|options}/{file}.webp

 Behind nginx, bound to 127.0.0.1 only. nginx terminates HTTPS and talks
 to these over the loopback; they are not addresses to browse the app at.
 Web (Vite / static)    127.0.0.1:3000
 API (FastAPI)          127.0.0.1:8000
 API docs (Swagger)     127.0.0.1:8000/docs           (not in production)
 OpenAPI schema         127.0.0.1:8000/openapi.json   (not in production)
 PostgreSQL             postgresql://127.0.0.1:5433/zenoeats
 Redis - Celery broker  redis://127.0.0.1:6379/0   (results: /1)
 Redis - cache/limits   redis://127.0.0.1:6380/0
